Behind the counter / Database

Where the papers
come from.

This site ships with the repository's database bundled as JSON, so it works offline. You can also connect the live FastAPI backend.

01 / Bundled database

Every row of seed_data.sql from edusphere-backend (commit 9607a80) was converted into JSON and embedded in this page. Additional curated entries point to verified official question-paper archives.

Source repository: github.com/Akash0747/edusphere-website

02 / Live backend

Point the archive at your FastAPI service. When connected, papers from /api/papers are merged into the shelf.

Offline — bundled database

03 / Admin sign-in

Requires a connected backend with the /api/auth/login route and CORS configured for this origin.

04 / Add a paper locally

Add a record to this browser's shelf. With a signed-in backend, the same form posts to /api/admin/papers.

05 / Portable data

Export your saved papers, solved marks, notes and locally added papers as JSON, or import them on another device.

This is a static site: no accounts, no server-side tracking. Your study data never leaves this browser unless you export it.
